# Журнал разработки мобильного приложения «Домофондар» (PROJECT_LOG.md)

## Дата: 2026-09-23 — Инициализация проекта и подготовка к сборке Android APK

### Описание изменений:
1. **Создана архитектура кроссплатформенного приложения**:
   - Технологический стек: React Native 0.76 + Expo SDK 52 + TypeScript + Expo Router v4.
   - Установлены и сконфигурированы пакеты: Zustand (управление состоянием), TanStack Query (кэширование API), Axios (сетевой клиент), React Hook Form + Zod (валидация форм), React Native Reanimated (анимации), SecureStore (безопасное хранение токенов), LocalAuthentication (биометрия), Notifications (push-уведомления).
2. **Конфигурация сборки и проекта**:
   - `app.config.ts` — полная конфигурация приложения для Android (пакет `ru.domofondar.app`, разрешения камеры, биометрии, уведомлений, splash screen, адаптивные иконки).
   - `eas.json` — конфигурация сборки APK (`preview` для тестирования, `production` для публикации AAB в Google Play).
   - `tsconfig.json` & `babel.config.js` — настроены пути импорта через алиас `@/*` на папку `src/`.
3. **Экраны и навигация (`app/`)**:
   - `app/_layout.tsx` — корневой лейаут с провайдерами темы, TanStack Query и проверкой авторизации.
   - `app/index.tsx` — стартовый шлюз (редирект в зависимости от наличия JWT токена).
   - `app/(auth)/login.tsx` — экран авторизации по номеру телефона и паролю в фирменном стиле сайта (темная тема `#0F172A`, изумрудный акцент `#10B981`).
   - `app/(auth)/register.tsx` — экран регистрации жильца с валидацией номера и пароля.
   - `app/(tabs)/home.tsx` — главная страница абонента: карточка лицевого счета и баланса, быстрые действия (создать заявку, оплатить ТО, связаться с диспетчером), последние заявки.
   - `app/(tabs)/requests/index.tsx` & `create.tsx` — просмотр и подача заявок на ремонт/обслуживание домофонов.
   - `app/(tabs)/payments/index.tsx` — история платежей и кнопка перехода к оплате.
   - `app/(tabs)/chat/index.tsx` — экран обратной связи с диспетчерской службой.
   - `app/(tabs)/profile/index.tsx` — профиль жильца, настройки темы и выход из аккаунта.
4. **Сетевой слой и состояние (`src/`)**:
   - `src/api/client.ts` — сетевой клиент Axios с автоматической подстановкой Bearer токена и логированием.
   - `src/store/auth.store.ts` — стор авторизации на Zustand с сохранением в SecureStore.
   - `src/store/theme.store.ts` — стор переключения тем (светлая/темная).
   - `src/theme/colors.ts` — палитра цветов идентичная веб-версии Домофондар.
5. **Ассеты**:
   - Сгенерированы и скопированы иконки: `icon.png`, `adaptive-icon.png`, `splash-icon.png`, `notification-icon.png`.
6. **Нативный пребилд Android**:
   - Выполнен `npx expo prebuild --platform android --clean`.
   - Сформирована готовая папка `android/` с Gradle-проектом, манифестом и настройками сборки APK.

### Структура проекта:
```
domofondar-mobile/
├── android/                 # Нативный Android проект (Gradle, AndroidManifest)
├── app/                     # Маршрутизация и экраны (Expo Router)
│   ├── (auth)/              # Экраны авторизации и регистрации
│   ├── (tabs)/              # Основные вкладки (Главная, Заявки, Платежи, Чат, Профиль)
│   ├── _layout.tsx          # Корневой лейаут
│   └── index.tsx            # Точка входа
├── assets/images/           # Иконки и заставки
├── src/
│   ├── api/                 # Axios клиент и эндпоинты
│   ├── config/              # Константы (URL бэкенда)
│   ├── store/               # Хранилища Zustand (auth, theme)
│   └── theme/               # Стили и цвета
├── app.config.ts            # Конфигурация Expo
├── eas.json                 # Профили сборки APK/AAB
├── package.json             # Зависимости проекта
└── tsconfig.json            # Настройки TypeScript
```
