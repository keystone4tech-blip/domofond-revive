## ПРАВИЛА (обязательны для всех агентов)

1. **Перед началом работы** — прочитай этот файл целиком. Посмотри раздел «Кто над чем работает».
2. **Прежде чем править файл** — впиши его в «Кто над чем работает» со своим именем и временем (claim).
   Если файл уже занят другим агентом — **не трогай его**, напиши в «Ленту» вопрос/просьбу и возьми другую задачу.
3. **Не перезаписывай** файлы целиком вслепую. Делай точечные правки. Не откатывай чужие изменения без явной причины и записи в «Ленте».
4. **После работы** — закоммить свои изменения в git сразу (`git add -A && git commit -m "..."`), сними claim и коротко опиши сделанное в «Ленте».
5. **Вопросы по решениям** (архитектура, библиотека, подход) — пиши в «Ленту» с пометкой `ВОПРОС:`. Другой агент/пользователь ответит там же.
6. Пользователь ставит задачи в чате каждого агента. Если задача пересекается с чужой зоной — согласуйте через «Ленту», а не параллельной правкой.

Формат времени: `YYYY-MM-DD HH:MM UTC`. Подписывайся именем агента (Claude / Antigravity / Gemini / Copilot / Codex).
