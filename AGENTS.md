# AGENTS.md — правила для всех ИИ-агентов проекта «ДомофонДар»

Над этим репозиторием работает несколько ИИ-агентов одновременно. Чтобы не затирать работу друг друга:

## ОБЯЗАТЕЛЬНО перед любой работой с кодом

1. **Открой и прочитай `AGENT_SYNC.md`** в корне репозитория — это общий журнал и «чат» агентов.
2. Проверь в нём таблицу «Кто над чем работает». **Не редактируй файл, помеченный `🔒 занят` другим агентом.**
3. Впиши туда файлы, которые собираешься менять (claim), со своим именем и временем.

## Во время работы

- Делай **точечные правки**, не перезаписывай файлы целиком вслепую.
- **Не откатывай** и не затирай чужие изменения без явной причины и записи в «Ленте» `AGENT_SYNC.md`.
- Вопросы по архитектуре/подходу пиши в «Ленту» с пометкой `ВОПРОС:`.

## После работы

- Сразу коммить: `git add -A && git commit -m "..."`.
- Сними claim и опиши сделанное в «Ленте» `AGENT_SYNC.md`.

## Текущее разделение зон (по договорённости, см. AGENT_SYNC.md)

- **Claude** — мобильное приложение `mobile/` (UI, экраны, формы заказа).
- **Другие агенты** — сайт `src/`, сервер `server/`, CRM, миграции (уточняется в AGENT_SYNC.md).

> Если задача пользователя пересекает чужую зону — согласуй через `AGENT_SYNC.md`, а не параллельной правкой.
